# Ethan Bai - Game Design Portfolio

Astro source for [ethanbaiii.github.io](https://ethanbaiii.github.io/).

## Local development

Use Node.js 24 or a compatible version supported by Astro.

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
```

The build generates the static website in `dist/` and verifies internal links and media references. Generated files and dependencies are not committed.

## GitHub Pages

In repository Settings, open Pages and select GitHub Actions as the source. The deployment workflow builds and publishes pushes to `main`; it can also be run manually from Actions.

## Content

Website pages are in `src/pages/`, project text in `src/content/current/`, shared copy and media metadata in `src/data/`, and web media in `public/media/`.

Public project descriptions preserve individual and team contribution boundaries. STHH project images and videos are not included. Private source materials, original development projects, and local review files are kept separately.
